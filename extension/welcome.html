Private by design

Welcome to the Commit extension

This extension tells the Commit app on this computer which website you are on and for how long, so your weekly report can show where your time went.

What is collected

  • The website domain (for example youtube.com), never the full address.
  • The page or video title — used only to choose a category (Work, Learning, Entertainment…), then thrown away. It is never stored.
  • The time you spend on the site.

What is never collected

  • Page content, things you type, form inputs or passwords.
  • Full web addresses (URLs).
  • Anything in incognito windows — the extension does not run there.

Where it goes

Only to the Commit app on this computer, at http://127.0.0.1. The extension has no permission to contact any other server. If you turned on "title categorisation with my own API key" in the Commit app, the app sends a shortened title (without e-mails, links or long numbers) to your chosen AI provider.

Don't track a website

Click the Commit icon in the toolbar and press Don't track, or add a domain such as bank.com to the list. Time on those sites appears only as "Private", without the site's name.

Connect to the Commit app (once)

  1. Start the Commit app (python -m agent.main).
  2. In the menu bar: Commit → Settings → Extension pairing token… and copy the token.
  3. Click the Commit icon in Chrome's toolbar, paste the token under Pairing, and press Save. The status should change to Connected.
